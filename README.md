# Cited by Newvora

Shopify app that scores and fixes product data so AI shopping agents (ChatGPT, Gemini, Copilot, Perplexity) recommend a store's products.

- Live: https://cited.newvora.in (embedded in Shopify admin)
- Stack: Shopify React Router app template, Polaris web components, Prisma + Postgres (Supabase, Mumbai), Vercel (bom1)
- Health check: `/healthz`

Built from Shopify's [React Router app template](https://github.com/Shopify/shopify-app-template-react-router).
